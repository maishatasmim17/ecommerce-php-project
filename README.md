# E-Commerce Website

## Project Overview
This is an online shopping website developed using PHP and MySQL.

Users can browse products, add items to cart and complete checkout.

## Technologies Used

- PHP
- MySQL
- HTML
- CSS
- JavaScript

## Features

- User registration/login
- Product listing
- Shopping cart
- Checkout system
- Admin panel

## Dependencies

- XAMPP
- Apache Server
- MySQL Database

## How to Run Locally

1. Install XAMPP
2. Copy project folder into htdocs

Example:

C:\xampp\htdocs\final

3. Start Apache and MySQL from XAMPP

4. Import database into phpMyAdmin

5. Open browser:

http://localhost/final
